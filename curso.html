Curso HTML

Guía

Unidad 1: Introducción

Conceptos iniciales para comenzar a trabajar con HTML.

Unidad 2: Etiquetas

Uso de etiquetas HTML y estructura semántica. Se trabajan encabezados, párrafos, listas, enlaces, imágenes, tablas y formularios.

Unidad 3: Formularios

Creación de formularios accesibles mediante label, campos de texto, correo, números, botones y mensajes de validación.

Unidad 4: CSS

Introducción a selectores, propiedades, modelo de caja, tipografías, colores, espaciado, tarjetas, navegación y diseño responsive.

Unidad 5: JavaScript

Variables, tipos de datos, funciones, eventos y manipulación del DOM. Estos conceptos permiten agregar interactividad sin cambiar la estructura HTML.

Unidad 6: Accesibilidad

Buenas prácticas para navegación con teclado, foco visible, texto alternativo, contraste, jerarquía de títulos y formularios comprensibles.
