Inicio

Bienvenido a mi sitio web, un espacio práctico para aprender los fundamentos del desarrollo web. Acá vas a encontrar contenidos sobre HTML, CSS, JavaScript y accesibilidad, organizados de forma clara para que puedas avanzar paso a paso.

HTML

Aprendé a estructurar páginas con etiquetas semánticas, formularios, enlaces, imágenes y contenido accesible.

CSS

Descubrí cómo aplicar colores, tipografías, espaciado, diseño responsive y estilos visuales.

JavaScript

Agregá interactividad con eventos, validaciones, fechas, galerías, formularios y cambios de tema.

Accesibilidad

Conocé buenas prácticas para que el contenido pueda ser utilizado por más personas y dispositivos.

Video: desarrollo web

Una breve presentación visual de las tecnologías que forman parte de este sitio: HTML para la estructura, CSS para el diseño y JavaScript para la interacción. También se destaca la importancia de la accesibilidad.

¿Qué podés aprender?

HTML semántico

Aprendé a organizar el contenido con encabezados, párrafos, listas, enlaces, imágenes, formularios y elementos semánticos. Una estructura clara mejora la comprensión del contenido y facilita su mantenimiento.

CSS responsive

Trabajá con tipografías, colores, espacios, tarjetas, navegación y diseños adaptables. El objetivo es que el sitio conserve una buena experiencia tanto en pantallas grandes como en celulares.

JavaScript

Usá variables, funciones, eventos, condiciones y manipulación del DOM para crear validaciones, galerías, menús, relojes, formularios interactivos y cambios de tema.

Accesibilidad

Aplicá texto alternativo, foco visible, navegación mediante teclado, etiquetas de formulario y suficiente contraste para que más personas puedan utilizar el sitio.
